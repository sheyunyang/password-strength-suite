# 密码强度检测与生成套件

> 分类：密码学与编码 ｜ 编号：项目 1 / 67 / 300 ｜ 生成日期：2026-10-06

## 简介
评估任意密码的强度与破解时间，生成符合策略的强随机密码，并量化密钥随机性。

## 功能清单
- 密码强度检测
- 强密码生成器
- 信息熵计算

## 使用方法
1. 直接用浏览器（Chrome / Edge）双击打开 `index.html`，无需安装任何东西。
2. 所有计算均在本地浏览器完成，断网也能用，数据不会上传到任何地方。
